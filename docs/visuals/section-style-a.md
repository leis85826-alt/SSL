# A 风格道路断面接入

日期：2026-10-26。按用户要求将断面与 A 精细矢量彩平统一。本轮仅修改 SVG 表现层。

## 实现

- 新增 `web/section-renderer.js`，与平面共享植物配色和树冠轮廓，增加枝叶层次、树干、林下植物、铺装和土层纹理、组成编号、尺寸及植物图例。
- 由 `web/plant-workspace.js` 调用，`web/index.html` 加载；平面上的 A / 原简图开关同时控制断面。只保存原有绘图偏好，不修改项目、历史版本、M05 或云端存储。
- 道路顺序与宽度读取已保存方案；33m示例仍为3/2.5/11/11/2.5/3m，典型树位断面保持两株乔木。独立树池与连续绿带分别表现。
- 分段方案按各部位、各段品种展示典型断面，最多12图并提示截取；其他部位保持典型配置，不宣称是所有分段的同步桩号剖切。
- 原 SVG 导出按钮输出当前风格，使用内嵌 defs/use/pattern，无外部图像依赖；已有方案无需再次生成或付费调用模型。

横向宽度按输入绘制。树高、冠幅、根系、结构层和海绵下凹深度均为示意，并在图内标注；不生成未经确认的工程尺寸、植物实例或工程量。
