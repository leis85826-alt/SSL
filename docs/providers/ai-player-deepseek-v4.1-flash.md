# 工程量专用 DS-V4.1-Flash

依据：用户提供的 Ai头号玩家 接入文档，model为deepseek-v4.1-flash，聊天模型，文档声明支持图文输入、工具调用、长上下文和OpenAI Chat Completions。基础地址https://api.lk888.ai/v1，Bearer鉴权，流式终止[DONE]，支持response_format。本次不把文档声明当成真实账户权限或图纸统计准确性实测。

用途：仅工程量清单识别、标准段PDF图纸统计、信息价候选匹配。独立设置入口“工程量模型设置”，独立加密cookie __Host-roadscape-quantity，90天。图片模型仍为其自身配置，方案模型亦保留。默认不复用任何其他密钥；用户可明确勾选沿用同服务商地址的图片模型密钥。换地址不转发旧密钥。

同源接口：/api/quantity/config GET/POST/DELETE，/api/quantity/analyze POST，/api/quantity/vision-test POST，/api/quantity/drawing POST。复用现有目的地址检查、HTTPS/同源策略、会话身份、输出脱敏及180秒模型超时。不自动重试。

图纸：每次勾选一份PDF，选择一页。本机先低分辨率检测空白边缘，再高清渲染选中页，提供概览与最多6张重叠细节图。图像经image_url提交，文本文件仍走提取文字。图像候选必须人工复核；label引用含原标注数量，symbol_count只允许概览图并为每株返回归一化计数框，框数须等于数量且不能重复。不根据未知密度猜数量，也不将面积、标注次数或方形设施混算成株数。

候选保存图面快照至IndexedDB，标记框与图片位置随候选显示，确认后追加清单，金额及长度换算由程序计算。图像识别不能做逐字原文校验，界面明确待人工复核；规格、面积或计数的语义准确性不能由字段校验保证。

验证：66项Node测试通过，新增配置/密钥复用显式选择、图片/方案配置隔离、专用模型图像请求、候选区域与计数框校验；浏览器验证设置、实际PDF裁切/渲染及图像载荷、候选图像展示、确认入表和原Excel/PDF文字匹配。用户PDF仅作本地渲染预检，没有上传到仓库或调用真实模型。真实模型能力和准确性需用户账户实测。
