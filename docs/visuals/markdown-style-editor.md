# 网页 Markdown 风格编辑器

2026-10-29。按用户要求，在独立AI绿化效果图页面保留Markdown上传，并增加直接编写、编辑和保存入口。

## 使用

- 左侧“我的效果图风格”：上传 `.md/.markdown` 后点击“编辑Markdown”；没有文件时可“直接编写Markdown”。
- 大编辑窗口支持修改文件名与正文、实时字数提示、恢复打开窗口时的保存内容、取消及保存。手机布局的标题和保存按钮保持可见，正文区可滚动。
- 非空UTF-8文字最多10000字、64KB，不静默截断。保存后刷新可恢复，下载当前Markdown与初始文件；后续图片请求使用当前保存内容。
- 编辑/保存不调用模型、不改变道路及植物方案签名、不创建图片任务或修改待查询任务。文字内容仅作为数据，不执行HTML或脚本。

## 数据保护

每次实际改动保存为新IndexedDB文件和新的摘要，不覆盖旧fileId。`effectStyle.sourceFile`通过嵌套fileId引用最初文件，既有图片仍引用生成时的保存版本，完整工作空间备份可收集两者。取消、内容无效、项目切换、本机保存失败或检测到其他标签更新时保留当前风格；失败时编辑文字留在窗口供复制和重试。异步保存期间禁用输入，窗口取消后不继续写回项目。关闭窗口或刷新会丢弃未保存编辑，保存内容仍保留。

数据继续保存在当前浏览器，R2暂停状态及云端功能不变。用户上传的实际项目Markdown没有加入源码或提交Git。
