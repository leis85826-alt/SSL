# DS-V4-Pro 植物配置接入

按用户提供的服务商文档，固定使用 `https://api.lk888.ai/v1/chat/completions`、`deepseek-v4-pro`、Bearer 鉴权。采用非流式 Chat Completions 与 JSON 输出，使用文档内的 max_tokens、response_format 参数。不执行导入链接附带脚本，不复用此前在聊天中出现的密钥。

模型接收确认后的道路结构、项目条件、所选案例及规范文字、当前方案与调整意见。输出植物清单、分部位描述及可选分段数据；服务端检查范围、品种关联与数值，前端按原道路结构生成 SVG 平面和断面。附件图片原件不发送，历史图片和历史方案仍可查看及导出。

密钥通过网页设置提交，保持身份绑定的加密 HttpOnly 会话，最长8小时。会话同时绑定服务商与模型，旧服务商密钥不会转发给新服务商。请求超时180秒，包括响应正文读取，不自动重试；失败不覆盖原方案。测试连接发送最小聊天请求，说明可能产生少量调用费用。

验证：服务端模拟标准成功响应、分段数据、鉴权/来源、旧会话隔离及错误；浏览器验证配置、生成/调整、SVG、历史版本、错误保留和手机布局。真实服务商调用需要用户在设置中填写新密钥后测试，不将模拟成功表述为真实模型已跑通。
