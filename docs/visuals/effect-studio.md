# 独立 AI 绿化效果图页面与 Markdown 风格文件

2026-10-26。主导航在“方案工作台”之后新增“AI 绿化效果图”，原工作台不再内嵌图片生成栏目。复用纳米香蕉2.1设置及原任务协议，不修改服务商接口或聊天方案功能。

## 使用与数据

1. 进入新页面，选择已有项目；没有保存植物方案时不能创建图片任务，可返回方案工作台生成。
2. 左侧上传一份 `.md` / `.markdown` 风格文件，支持查看纯文字、替换、下载原件及移除。只接受有效UTF-8、非空、最多64KB且10000字，不静默截断；失败保留原风格。
3. 选择比例、分辨率、思考等级与补充要求，点击生成时发送已保存方案文字、风格文字与补充要求；图片按服务商计费。上传/切换文件不调用图片模型，文件中的HTML/脚本只显示为文字，应用不会访问其中链接。
4. 所有旧效果图与任务仍按原项目保存，任务可继续查询，不自动重复创建；新图片记录当次风格文件名称/摘要。移除风格不会删除历史效果图或其原附件。

风格元数据及文字存入项目 `effectStyle`，原件以 `text/markdown` 存入IndexedDB，通过 `fileId` 引用；完整工作空间备份包含原件与引用。风格不参与植物方案签名，不更新植物数量、道路尺寸、工程坐标或方案版本。R2/云端存储继续暂停，上传文件仍是本机保存，用户点击生成才发送文字到图片服务商。

生成前检查完整提示词不超过16000字，超过时提示精简，不先创建任务。默认1K及既有90天加密模型会话保持不变。图片结果仍是服务商链接，备份不含远端图片原件，请另存原图。
