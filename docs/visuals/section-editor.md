# 断面素材库与交互编辑器

入口：案例库 → 断面素材库；方案工作台 → 道路断面 → 打开断面编辑器。

内置11种透明植物轮廓；上传PNG/WebP每张最多8MB、4000万像素。上传文件存IndexedDB，目录存工作空间 sectionMaterials。支持名称和分类编辑、目录删除、素材备份导入导出。素材目录删除不清除已保存实例使用的文件。

编辑器默认锁定道路底图，初排读取原植物插画布局。支持点击或拖入素材、鼠标移动、右上角等比例缩放、放大缩小、复制删除、翻转、置顶置底、地面吸附开关、撤销重做。对象布局逐操作提交，保存失败回退；参考高度按道路横向比例换算，不作为工程树高。每项目保存sectionScene，实例记录素材快照元数据和文件引用，不保存重复大图到localStorage。几何或植物方案发生变化时不直接套用旧布局，进入新初排前确认。

导出SVG内嵌素材，隐藏选框和控制点；独立编辑备份包含布局及自定义PNG，导入要求当前方案来源一致。素材及布局均为浏览器本机数据，不跨设备自动同步；请分别导出素材备份与编辑备份。通用工作空间备份不作为新模块文件完整备份的保证。

验证：49项Node回归通过；新Playwright测试覆盖素材上传、删除目录保留实例、复制删除、撤销重做、鼠标移动及角点缩放、地面吸附、刷新持久化、原方案不变、SVG内嵌导出、编辑备份恢复、素材备份恢复及存储失败回退。原平面与断面浏览器回归通过。本地Worker构建与产物校验通过。未调用收费模型或修改生产用户数据。

## 纯线稿风格

编辑器顶部“断面风格”选择素材拼贴或纯线稿。白底、灰绿细线植物及简化车辆人物；没有项目数据的建筑不凭参考图添加。内置植物按原实例的位置、宽度、高度生成矢量轮廓、枝干与叶片细节，上传素材以透明通道轮廓线化，非透明图片只能得到矩形边缘。切换不修改道路几何、对象坐标和尺寸，参与撤销重做、保存刷新、编辑备份及SVG导出。重新初排保留风格选择。

验证新增风格切换、对象数据不变、全内置素材线稿SVG不含光栅图片、撤销重做、刷新恢复和导出检查。

## 预览区风格选择

“断面编辑图”的图面上方直接提供断面风格下拉框，无需打开编辑器。选择自动保存到项目sectionScene.style，并与编辑器同步。已有对象坐标、大小与道路数据不变。无布局时创建初排；旧布局与新方案不符时要求先进入编辑器确认，不默默覆盖旧布局。入口脚本版本参数一并更新。

浏览器新增验证预览区切换、坐标不变、刷新恢复、打开编辑器风格一致，以及编辑器修改后预览同步。
