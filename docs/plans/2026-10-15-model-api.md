# TokensFactory 模型接入

使用用户指定的 https://tokensfactory.cc/v1 与 gpt-6-sol，不使用聊天中披露的密钥。通过官方OpenAI Chat Completions文档核对兼容请求格式；第三方的具体模型供应与参数兼容性仍以实际连接测试为准。

架构：现有界面源文件移至web，保留浏览器本机项目库。静态托管迁移为无依赖Worker，构建时嵌入静态资产。模型请求由同源服务端代理到固定提供商，避免任意URL代理或密钥经重定向转发。现有project_id、网址和私人访问权限不变。

密钥通过HTTPS设置页面提交，服务器使用运行时secret进行AES-GCM加密，身份绑定、最长8小时，以Secure/HttpOnly/SameSite=Strict会话cookie承载密文。密钥不进入项目、备份或localStorage，不长期存储；不建新的OAuth或云项目数据系统。运行时secret不进入源码。非登录请求拒绝，写请求核对Origin。关闭浏览器或过期需重新配置。

用户选择规则/API生成。API模式发送项目条件、确认尺寸、所选案例/规范文字、当前方案和调整文字，不发送原附件。输出为有界JSON设计数据，经结构校验和现有数值规范校核后才写入方案及版本；失败或输入变更保留旧结果，不静默退回规则。分段JSON驱动平面色块和各段典型断面。模型文字不作为规范达标或施工图结论。

验证使用模拟上游，不使用真实密钥消费用户额度。覆盖会话加密/身份/Origin、敏感数据不回显、上游错误/结构校验、分段同步、规范拦截、取消/过期、版本及既有规则功能。发布后用户需填写新密钥并测试真实服务商连接。
