# Cloudflare 在线模型生成部署

当前静态资源上传只运行 `web/`，没有 `/api/model/*` 服务。此配置同时部署 Worker 模型代理和静态工作台。默认服务商 `https://api.lk888.ai/v1`、默认模型 `deepseek-v4-pro`；模型设置支持编辑其他 OpenAI 兼容服务商基础地址与聊天模型。不接入 M05 新算法或云端项目库。

## 先明确密钥与身份

- 每位使用者在网页“模型设置”填写自己的服务商 API 密钥；不是共用站长密钥。
- Worker 用 `ROADSCAPE_SESSION_SECRET` 加密会话，浏览器通过 Secure/HttpOnly/SameSite=Strict Cookie 保存密文，保存后有效90天，刷新或完全重开同一浏览器自动恢复。这个 secret **不是模型 API 密钥**。
- Cloudflare入口生成独立浏览器身份并覆盖客户端提供的原平台身份头；这是浏览器会话隔离，**不是账户登录或项目访问权限系统**。原 Sites 入口不变。
- 模型配置/生成需HTTPS、同源写请求；原始项目/案例/规范文字会发送给保存的地址对应的模型服务商。附件原件不发送。
- 不提交任何真实密钥，不写入普通 vars、源码、LocalStorage、项目或备份。浏览器本机项目仍不跨设备同步。

## 使用命令行发布独立预览（推荐先验证）

在自己的电脑解压源码包，打开包含 `wrangler.jsonc` 的根目录，安装现代 Node.js（本次验证为24）。以下命令使用已验证的 Wrangler 4.152.0。

```bash
npx wrangler@4.152.0 login
```

授权自己的 Cloudflare 账号后，先设置加密 secret：

```bash
npx wrangler@4.152.0 secret put ROADSCAPE_SESSION_SECRET
```

按命令提示在本机输入高强度随机字符串（建议32随机字节的64位十六进制表示，至少32字符）。可以使用系统密码生成器，或在本机运行 `openssl rand -hex 32`。**不要把生成值发到聊天或提交Git**。如果CLI提示该独立Worker尚不存在，按提示创建 `roadscape-model-preview`，然后设置secret。

```bash
npx wrangler@4.152.0 deploy
```

Wrangler读取 `wrangler.jsonc`，先运行自定义构建，然后上传 `worker/cloudflare-entry.js` 与 `web/` 资源。静态大图不嵌入Worker脚本。使用CLI实际输出的网址，不预先推测部署地址。

默认名称 `roadscape-model-preview`，因此不会覆盖现有 `winter-poetry-86b3` 静态站点。新域名不会自动出现旧域名的本机数据；不要清空原浏览器或假设普通备份包含全部历史图片，参考M05审计报告。

## 如果希望通过GitHub自动部署

1. 使用 GitHub `leis85826-alt/SSL` 的 `feature/cloudflare-model` 开发分支；核对该分支包含本文、wrangler.jsonc 和 worker/cloudflare-entry.js。不要连接尚未包含模型接入代码的 main 分支。
2. Cloudflare创建**Workers应用**，连接该分支。此版本需要执行Worker，不再用只上传静态文件的方式。
3. 构建命令可留空（wrangler.jsonc 的 build.command 已定义构建），部署命令填 `npx wrangler@4.152.0 deploy`；根目录为仓库根目录。
4. 在该Worker的 Settings → Variables and Secrets 添加类型为 Secret 的 `ROADSCAPE_SESSION_SECRET`，保存后重新部署。
5. 不把服务商 API 密钥设置为公用站点变量；由使用者在网页中填写。

如需升级现有网址，须明确决定覆盖原Worker后，将wrangler.jsonc中的name改为 `winter-poetry-86b3` 并在该Worker设置secret。先完成预览验收和代码审阅；本次未修改账号设置、推送或发布生产。

## 上线后的验收

### 切换聊天模型

在“模型设置”的“模型名称 / ID”直接填写服务商提供的ID，或先保存有效密钥、点击“读取可用模型”，再从输入框候选中选择。已有有效会话时，密钥留空即可保留现有密钥并保存新的模型。API 基础地址可编辑；换地址必须填写新地址对应的密钥，同一地址下切换模型可以留空保留。

服务端将所选模型写入加密会话，GET配置、连接测试、真实Chat Completions请求和结果元数据均读取该值，不再固定DS-V4-Pro。界面的顶部/侧栏入口和生成方式标签同步更新，刷新后恢复；已有生成结果仍保留其实际历史模型，不随新配置改写。

模型清单由新增的同源`GET /api/model/models`代理到服务商`GET /v1/models`，使用当前保存的服务商地址、禁止跳转、10秒超时、限制响应大小，仅返回去重后的有效ID。读取失败可手填；不因清单不可用阻止手工配置。清单不保证模型都支持聊天/JSON或当前密钥有调用权限，图片模型不适用。不自动试用、计费调用、换回默认模型或重试；选择新模型后由用户手动测试连接。

验证：24项Node测试通过；本地HTTPS浏览器模拟验证可编辑名称、读取清单、密钥留空切换、标签/请求一致、刷新恢复、失败保留原方案。未调用真实收费模型，不能以这些测试保证用户账号有新模型权限或推理提速。

1. 打开 `/api/model/config`：应返回JSON，包含 `configured:false`、`ready:true`；不应返回静态HTML、404或原Sites登录提示。
2. 网页打开“模型设置”，输入自己的有效API密钥，点击“保存并记住配置”，再点“测试已保存连接”。真实调用由服务商计费，不自动反复重试。
3. 确认道路结构和尺寸，生成方式选择所选模型的“方案＋矢量图”，点击生成。结果须出现API模型标记以及模型植物说明、平面和断面。
4. 失败时检查页面提示与Cloudflare日志；不把模拟测试通过视为真实账户/额度/模型权限通过。不要公开密钥、请求中的项目资料或未经脱敏的日志。
5. 同一浏览器保存并刷新验证；另一浏览器必须填写自己的密钥。清除模型会话后，现有规则生成仍可用。

## 开发验证和回退

### 长推理响应大小修复

旧代理将SSE封装、推理片段和最终方案全部计入2,000,000字节限制，可能在最终方案很小时提前报“模型响应过大”。现改为：累计数据流16 MiB、方案正文1 MiB、单条/未结束事件最多1,048,576字符；180秒上游超时保留。推理片段仍不存入方案、不回传原文；日志只增加字节数、事件数与正文大小计数。

回归测试使用约2.1MB合成推理流和236字节最终方案：旧代码复现拒绝，修复后通过；另验证超大流、超大正文及未结束事件被拒绝并取消读取。共15项Node测试通过，不代表已验证真实付费上游或线上部署。此修复不改变模型选择、计费策略、项目数据或绘图逻辑，也不保证模型推理本身提速。

### 流结束和超时阶段修复

用户提供的[服务商API文档摘要](providers/ai-player-deepseek-v4-pro.md)确认流式响应以`[DONE]`结束。旧实现收到结束标志后仍等待HTTP EOF；现收到该标志立即停止读取、取消reader并校验最终方案。仍允许读取finish_reason之后、DONE之前的usage或错误；length截断标志不会被DONE覆盖为成功。

180秒上限保留，不猜测未经文档说明的快速/关闭推理参数。超时错误新增等待阶段和正文累计字数；日志增加流量、最后数据时间、推理字符计数及白名单token用量，不输出推理/方案原文或密钥。模拟覆盖保持连接未关闭、分块DONE、末尾usage、finish_reason之后的错误、截断输出和不同超时阶段。线上这次超时是否由等待EOF引起尚无证据；如果180秒内仍没有DONE或完整结果，仍需服务商耗时/调用记录定位，不能宣称服务响应已提速。

## 可编辑地址与自动记住配置（本轮更新）

同时保存基础地址、模型 ID 与密钥，有效90天。两枚 Secure/HttpOnly/SameSite=Strict Cookie 均设置 Max-Age=7776000；密钥 AES-GCM 加密，仍绑定浏览器身份及站点。保存时刷新原浏览器身份 cookie 的到期时间，并保留身份 ID，让已有8小时会话在重新保存后能够升级为持久配置。旧会话不会仅因更新代码自动延长：更新后请保存一次。客户端及项目/备份/localStorage 均不获取明文密钥。

90天到期、手动清除网站数据/配置、更换浏览器或轮换服务端 secret 后需要重新配置。浏览器自身的 Cookie 策略仍可能提前清理。另一台电脑不自动同步密钥；没有引入云端共享密钥库。

基础地址默认示例含 `/v1`，支持自定义路径如 `/openai/v1`；仅填写域名时补 `/v1`，粘贴 `/chat/completions` 或 `/models` 完整端点时移除端点尾部。保存成功后显示归一化地址。只接受公网域名 HTTPS 标准端口，不含用户信息、查询参数、fragment 或 IP 字面量；更换地址时服务端拒绝沿用之前密钥。修改了表单但未保存时，读取清单和测试会提示先保存，避免测试到上一套配置。

自定义地址在保存及每次调用前，经固定 Cloudflare DNS-over-HTTPS 地址查询 A/AAAA，拒绝内网、回环、链路本地及保留地址，8秒解析上限；DNS 请求无模型密钥。原默认服务商保留原访问路径，不新增其 DNS 服务依赖。解析失败时拒绝发送密钥，不静默降级。DNS 预检与实际网络连接不是地址绑定，不能替代部署环境的网络出口隔离；平台应继续禁止访问私有网络。所有服务商请求禁止重定向。接口清单、测试、生成、结果元数据使用同一保存地址，仍只支持 OpenAI 兼容聊天/JSON，不意味着支持图片模型。

本轮验证：29项 Node 接口回归通过；本地 HTTPS Chromium 持久用户目录测试验证真正关闭和重开浏览器后恢复配置、可编辑地址、归一化展示、模型清单/测试/生成使用自定义地址、换地址不复用密钥、清除配置及密钥不进入 localStorage。所有上游为模拟，未使用真实密钥或调用收费服务。Cloudflare dry-run 验证后通过原 `feature/cloudflare-model` 分支交付；不能将本地模拟结果视为线上新服务商权限通过。
