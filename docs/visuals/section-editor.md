# 断面素材库与交互编辑器

入口：案例库 → 断面素材库；方案工作台 → 道路断面 → 打开断面编辑器。

内置11种透明植物轮廓；上传PNG/WebP每张最多8MB、4000万像素。上传文件存IndexedDB，目录存工作空间 sectionMaterials。支持名称和分类编辑、目录删除、素材备份导入导出。素材目录删除不清除已保存实例使用的文件。

编辑器默认锁定道路底图，初排读取原植物插画布局。支持点击或拖入素材、鼠标移动、右上角等比例缩放、放大缩小、复制删除、翻转、置顶置底、地面吸附开关、撤销重做。对象布局逐操作提交，保存失败回退；参考高度按道路横向比例换算，不作为工程树高。每项目保存sectionScene，实例记录素材快照元数据和文件引用，不保存重复大图到localStorage。几何或植物方案发生变化时不直接套用旧布局，进入新初排前确认。

导出SVG内嵌素材，隐藏选框和控制点；独立编辑备份包含布局及自定义PNG，导入要求当前方案来源一致。素材及布局均为浏览器本机数据，不跨设备自动同步；请分别导出素材备份与编辑备份。通用工作空间备份不作为新模块文件完整备份的保证。

验证：49项Node回归通过；新Playwright测试覆盖素材上传、删除目录保留实例、复制删除、撤销重做、鼠标移动及角点缩放、地面吸附、刷新持久化、原方案不变、SVG内嵌导出、编辑备份恢复、素材备份恢复及存储失败回退。原平面与断面浏览器回归通过。本地Worker构建与产物校验通过。未调用收费模型或修改生产用户数据。

## 纯线稿风格

编辑器顶部“断面风格”选择素材拼贴或纯线稿。白底、灰绿细线植物及简化车辆人物；没有项目数据的建筑不凭参考图添加。内置植物按原实例的位置、宽度、高度生成矢量轮廓、枝干与叶片细节，上传素材以透明通道轮廓线化，非透明图片只能得到矩形边缘。切换不修改道路几何、对象坐标和尺寸，参与撤销重做、保存刷新、编辑备份及SVG导出。重新初排保留风格选择。

验证新增风格切换、对象数据不变、全内置素材线稿SVG不含光栅图片、撤销重做、刷新恢复和导出检查。

## 预览区风格选择

“断面编辑图”的图面上方直接提供断面风格下拉框，无需打开编辑器。选择自动保存到项目sectionScene.style，并与编辑器同步。已有对象坐标、大小与道路数据不变。无布局时创建初排；旧布局与新方案不符时要求先进入编辑器确认，不默默覆盖旧布局。入口脚本版本参数一并更新。

浏览器新增验证预览区切换、坐标不变、刷新恢复、打开编辑器风格一致，以及编辑器修改后预览同步。

## 彩色剪影替代纯线稿

按新参考图调整原line风格，界面名称改为“彩色剪影”，保留原样式值以兼容已保存布局。地面轮廓深灰3px，尺寸线维持细线；行人红色#dc3548，骑行者黄色#d6ad25，汽车深蓝#07506c，植物浅灰绿填色与枝叶细节。车辆按道路宽度组织，宽机动车道加入简化公交车。自定义透明素材按alpha形状着浅灰绿，不透明图仍会得到矩形剪影。道路顺序、尺寸及用户编辑对象位置大小保持。

新增浏览器检查地面线宽及三类配景颜色；保留风格切换、编辑、保存与导出回归。

## 保持素材树形与实例调色

彩色剪影不再生成通用矢量树冠，改为复用素材原始PNG、裁切区域及alpha透明轮廓，仅通过SVG颜色矩阵改变色调。保留树冠、枝干、内部明暗及实例位置、大小与翻转。内置与上传素材采用同一路径，SVG导出内嵌原图及颜色滤镜。

选中植物后工具栏“植物颜色”打开颜色选择器；恢复默认色只清除该实例plantColor。彩色剪影默认灰绿，素材拼贴默认原色。自定义颜色两种风格共用，保存为实例属性，不更改素材库文件。颜色参与撤销重做、复制、刷新和编辑备份。

验证新增原裁切区域保持、颜色更改不动几何、单株调色、撤销重做、恢复默认色、刷新后颜色保持、复制继承和导出包含颜色滤镜；原编辑器全流程回归。

## 实时调色修复

植物颜色监听input实时更新并保存，只重绘SVG画布，不重建原生color控件/工具栏。change结束本次选色。连续input共用一次撤销快照；工具操作、下次打开取色器和关闭编辑器会清理本次调色状态。保存失败回退当前帧并提示。

浏览器模拟仅input、未change的拖动选色，验证实例属性、滤镜和实际画布截图变化，原颜色控件保持连接；多次input后一次撤销恢复调色前状态。保留原保存、刷新、复制、备份和导出测试。

## 两种风格独立编辑

按用户确认，“素材拼贴”与“彩色剪影”各自保存植物布局、颜色和编辑历史。项目新增sectionScenes.collage/line，sectionScene保留为当前风格兼容镜像。旧共享布局在首次保存时各深复制一份作为起点，后续编辑仅更新当前风格；未确认保存时不删除旧数据。无旧布局时两种从同一初排深复制。撤销重做记录按风格分开，不跨风格撤销。

预览及编辑器切换均恢复目标风格自身布局。重新初排、单风格编辑备份恢复仅影响当前风格；编辑备份继续导出当前风格。方案变化导致目标布局过期时先在预览切换再进入编辑器确认，其他风格旧布局保持。

新增浏览器验证旧共享数据迁移、两种风格独立增删/调色/大小、独立撤销重做、切换及刷新恢复、保存失败同时保留两份布局。
